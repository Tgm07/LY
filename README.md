# Lyrics Stage updates

Current release: **1.2.0**

This repository hosts signed Lyrics Stage APK releases and the small `latest.json` manifest used by the app's direct updater.

The Android source code is not stored here.

Version 1.2.0 adds per-account cloud recommendation profiles, keeps local history and queues isolated between Google accounts, and introduces artwork-themed lyric cards that can be shared through Android's share sheet.
